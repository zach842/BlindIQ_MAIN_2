# BlindIQ

The no frills hunting logger: select a state and hunting category, record **Saw** and **Harvested**, and save your hunt.

## Develop and verify

Use Node 22 and pnpm 10.28.0, as declared in package.json.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm run build
pnpm preview
```

The production build checks app/cache versions, the hunting hub, selected IQ logo and the map-free production bundle. `dist/` is generated by the build and is not committed. Without Supabase configuration the app uses demo mode (`hunter` / `confidence`); demo records stay in this browser.

## Application and service files

| Path | Purpose |
| --- | --- |
| `src/` | React app, logger, regulations, accounts, maps and forecast panels |
| `public/` | App icons, field-guide images, attribution, service workers and PWA manifest |
| `supabase/` | Database migrations/setup SQL, Edge Functions and schedules |
| `forecasting/` | Deer/turkey source registry, pilot regions and weather pipeline |
| `notifications/` | Calendar readiness and source-review workflow |
| `tests/` | Regulation, logger, weather, notification, database and browser checks |
| `scripts/` | Build validation, automated tests, forecast worker and notification type check |
| `docs/` | Regulation evidence, forecasting design and current release notes |

Public legacy icons and versioned service workers are retained for installed-app compatibility. Database migration history is retained. Archived releases, screenshots and the old nested app are recoverable from Git history rather than duplicated in the current tree.

## Deployment

Vercel builds the repository root with `pnpm run build` and publishes `dist`. Use a branch and pull request, check the Vercel preview, then merge the reviewed update into `main` for production. See [deployment notes](DEPLOYMENT_NOTES.md).

Keep credentials in local environment files or hosting secret stores. The client reads public `VITE_` settings; never put a private/service-role key in a client variable.

Maps are excluded from the current build. Their USGS topo/aerial, browser-local spots, line/area planning and GeoJSON source infrastructure is preserved for future use.
