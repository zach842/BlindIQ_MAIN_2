# BlindIQ v1.70.0 — optional location weather

Hunt → Add weather → Use my location performs a one-time browser location request only after the hunter taps the button. Manual weather entry remains available. Approximate coordinates (rounded to three decimal places before transmission) are sent directly to the National Weather Service. Exact device coordinates are neither stored nor added to hunt records. Hunting state/category preferences are not changed by location.

The official NWS points endpoint supplies a station list. BlindIQ checks up to three nearest stations within 80 km (about 50 miles), seeking an observation with a usable temperature and a timestamp no more than two hours old (future timestamps beyond five minutes are rejected). Missing wind is omitted, not treated as calm. Weather is a nearby-station observation, not a claim about conditions exactly at the hunter's spot. The saved text includes Fahrenheit temperature, available conditions/wind, station identifier, approximate station distance and UTC observation time. It is saved in the existing hunt notes field and can be edited before saving. No database migration or paid weather API is required.

Location lookup has a 10-second device timeout and a 30-second overall deadline, with Cancel. Denied/unavailable/inaccurate location, offline mode, unsupported NWS locations, stale observations and provider failures leave any previous/manual weather unchanged. Manual editing, session reset or leaving the logger aborts pending work. Saving waits for lookup completion or cancellation so the saved weather cannot silently differ from a late response. No location permission is requested on app load or when simply opening Add weather.

Source and API contract: https://www.weather.gov/documentation/services-web-api (points → observationStations → stations/{id}/observations/latest). A live public Maryland reference-point lookup verified the complete provider response path. Weather can differ materially from station to field and is not a safety advisory or animal-movement prediction.

Validation: 78 unit/database tests; browser checks for explicit-only location requests, reduced coordinate precision, provider units/source/time, permission denial, offline/provider failures, cancellation and ignored late callbacks, disabled save while loading, reset protection, responsive widths and weather-note persistence without GPS. Existing logger, manual-weather/deletion and installed-cache upgrade/offline checks also pass. Production release guards continue to exclude map rendering.
